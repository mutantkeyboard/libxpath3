# libxpath3 API documentation

libxpath3 is an XPath 3.1 engine in C for documents parsed with libxml2.

See the [File List](files.html) for the public headers.

The tutorials, seven tested programs from a first query to untrusted
expressions, are in the repository:
<https://gitlab.gnome.org/mutantkeyboard/libxpath3/-/blob/main/doc/tutorial/README.md>

The git repository is hosted on GNOME's GitLab server:
<https://gitlab.gnome.org/mutantkeyboard/libxpath3>
